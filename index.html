📖 Шпаргалка терминов

База данных (БД) — организованная совокупность данных по правилам.
Таблица — набор однородных данных в строках и столбцах.
Запись (строка) — сведения об одном объекте.
Поле (столбец) — характеристика объекта.
Однотабличная (плоская) БД — все данные в одной таблице, без связей.
Первичный ключ (PK) — поле/набор полей, уникально идентифицирующих запись; не пуст.
Составной ключ — PK из нескольких полей.
Внешний ключ (FK) — поле, ссылающееся на PK другой таблицы; обеспечивает связь.
Связи: 1:1, 1:N (один ко многим), M:N (многие ко многим, через промежуточную таблицу).
Целостность: PK уникален и не пуст; FK ссылается на существующую запись; значения по типу.
Избыточность — повтор одних и тех же данных.
Аномалии — проблемы при вставке / обновлении / удалении из-за плохой структуры.
Нормализация — разбиение данных на связанные таблицы для устранения избыточности и аномалий.
СУБД — программа управления БД (MySQL, PostgreSQL). SQL — язык запросов.
