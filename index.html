📖 Шпаргалка терминов

База данных (БД) — организованная совокупность данных по правилам.
Таблица — набор однородных данных в строках и столбцах.
Запись (строка) — сведения об одном объекте.
Поле (столбец) — характеристика объекта.
Однотабличная (плоская) БД — все данные в одной таблице, без связей.
Первичный ключ (PK) — поле/набор полей, уникально идентифицирующих запись; не пуст.
Составной ключ — PK из нескольких полей.
Внешний ключ (FK) — поле, ссылающееся на PK другой таблицы.
Связи: 1:1, 1:N (один ко многим), M:N (многие ко многим).
Целостность: PK уникален и не пуст; FK ссылается на существующую запись.
Избыточность — повтор одних и тех же данных.
Аномалии — проблемы при вставке / обновлении / удалении.
Нормализация — разбиение данных на связанные таблицы.
СУБД — программа управления БД (MySQL). SQL — язык запросов.
